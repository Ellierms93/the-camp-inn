# The Camp Inn website prototype

Tablet-friendly GitHub upload: this project deliberately has only 3 files at the top level plus one `assets` folder. No build tools, terminal, npm or Codex are required.

## Upload from an Android tablet
1. Create/open your GitHub repository.
2. Tap **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
4. Create an `assets` folder (or upload the supplied assets into an existing `assets` folder): `hero.jpg`, `logo.png`, `alpacas.png`, `farm-family.jpg`.
5. Commit the files.
6. In **Settings → Pages**, deploy from the `main` branch / root if using GitHub Pages.

The ZIP contains the same structure so you can extract it in Android Files first.

## Current status
This is a real responsive front-end prototype. Date search, pitch selection, mobile navigation and the pitch modal work. Availability and payment are intentionally demo-only until the visual design is approved.
